《第十三中学：本站暂不开放》第一版
==================================

文件说明
--------
index.html   游戏入口
style.css    千禧年校园网站样式
 game.js     章节、谜题、提示、存档和结局逻辑
攻略.html    独立完整攻略（含全部答案与隐藏结局）
README.txt   本说明

如何游玩
--------
1. 将整个文件夹解压到电脑上。
2. 双击 index.html，用 Edge、Chrome 或 Firefox 打开。
3. 从首页开始，按章节提示调查网站内容。
4. 输入谜题答案后点击“提交查询”。正确答案会解锁下一章。
5. 每章可点击“查看提示”，逐级获取最多三条提示。
6. 游戏进度会保存在当前浏览器的本地存储中。请尽量使用同一浏览器继续游戏。
7. 点击侧栏“重置本机游戏进度”可清除进度并重新开始。

独立攻略
--------
攻略.html 与游戏分开。测试作者可以打开查看答案；向玩家发布时可以不提供攻略文件。

隐藏结局条件
------------
A：在侧栏打开“网页维护注释副本”，点击“记录这条线索”。
B：进入“旧档案室”，点击“记录线索：2004 年异常修改日期”。
C：进入“留言板”，点击“记录线索：维护员未完成日志”。
收集三条线索并完成第六章后，隐藏结局入口会出现。

技术与隐私
----------
本项目使用原生 HTML、CSS、JavaScript，无需安装、无后端、无外部网络请求。
不会访问用户的个人文件，不收集姓名、位置或其他个人信息。
游戏进度保存在浏览器本地存储中。不同浏览器或某些本地文件模式可能有独立存储空间。

注意
----
本故事中的临河县、第十三中学及所有人物均为虚构。游戏内的异常都是叙事设计，不代表真实学校或真实事件。
