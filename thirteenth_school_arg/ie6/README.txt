《第十三中学：本站暂不开放》IE 兼容版

启动方式：在 Internet Explorer 中打开本文件夹里的 index.html。
推荐分辨率：800×600 或更高。

兼容策略：
- 使用 HTML 4.01 Transitional 与传统表格/浮动布局风格。
- 不依赖外部 CSS、外部 JavaScript、HTML5、CSS3、localStorage、JSON、querySelector 或现代事件 API。
- JavaScript 使用 IE6 可识别的传统语法；谜题、章节解锁、提示、线索与结局均在本地页面内完成。
- 游戏尝试通过 Cookie 保存进度。不同 IE 安全设置、隐私设置及 file:// 本地打开方式可能阻止 Cookie；若关闭浏览器后进度未保留，请尽量在同一浏览器会话内完成，或将文件放在支持 Cookie 的本地/内网 Web 服务器下访问。
- 如果 IE 的脚本执行被禁用，游戏交互无法工作。请只对你信任的本地文件启用脚本。

这是单独的旧浏览器兼容实现，不会覆盖新版文件夹中的主游戏。
