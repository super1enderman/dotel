《临河十三中：本站暂不开放》
第一季 · 千禧年风格校园 ARG · 慢热心理恐怖
================================================================

一、这是什么
----------------------------------------------------------------
你找到了一个 2001 年建的县中教学点网站。它停在 2004 年 11 月 17 日 17:07。
这个班应该有 43 个人，全网却只查得到 42 个名字。

本作是纯静态网页，不需要安装、不需要联网、不需要服务器。
所有谜题都能从站内文字推出，不需要外部搜索，也不需要懂代码。

规模：64 个页面，正文约 3 万字，正常通关 2—3 小时，全收集 4 小时以上。
恐怖方式：只有文字。没有跳脸、没有鬼影、没有音效惊吓、没有血腥。


二、怎么玩
----------------------------------------------------------------
1. 双击 index.html（用 Edge / Chrome / Firefox 打开）。
   如果电脑上是 IE6—IE8，或者想用 IE 模式：进 ie6/index.html。
2. 从首页开始，把每个栏目都点一遍。建议拿一张纸，边读边记数字和日期。
3. 有些页面需要密码。密码规则写在站内，不在页面上直接给。
4. 结案报告（report.html）填写正确后可以进入结局。共 3 个结局。
5. 进度（已查阅页数）保存在本机浏览器里。
   换电脑时用 tools.html 里的“进度码”导出/导入。


三、文件说明
----------------------------------------------------------------
index.html         入口（现代版）
style.css          版式（CSS 2.1，两套版本共用）
extra.css          现代版装饰（IE6 不加载）

README.txt         本文件
images/            校徽、分隔线、NEW 图标
bak/20041117/      站内备份目录：README.txt、01.txt、02.txt、03.txt
robots.txt         站内文件
ie6/               IE6 兼容版（同一套 64 个页面，HTML 4.01 + ie6.css）

注意：ie6/ 目录里也有一份 bak/ 与 robots.txt，是同一批文件。


四、IE6 兼容版说明
----------------------------------------------------------------
ie6/ 下的每一个页面都满足：
 · HTML 4.01 Transitional，不用 HTML5 标签
 · 表格布局，不用 flex / grid / 定位
 · CSS 只用 CSS 2.1 属性，不用圆角、阴影、渐变、媒体查询
 · lh.js 全部为 ES3 语法（var、无箭头函数、无模板字符串、
   不用 JSON、不用 localStorage 强制依赖，取不到就退到 cookie）
 · 图片全部为 GIF，无 PNG 透明、无 data URI、无外部字体
 · 页面之间用真实链接跳转，不是单页应用

已知限制：本机没有 IE6 运行环境，兼容性是按上述规范逐项核对的结果，
未在真实 IE6 上做运行验证。若在 IE 模式中发现问题，请反馈具体页面。


五、给作者：怎么改内容
----------------------------------------------------------------
本项目由构建脚本生成，源码在 src/：

  src/data-core.mjs     学校信息、导航、42 名学生与成绩、表格工具
  src/pages-core.mjs    首页、简介、沿革、教师、地图、旧钟、登记簿、404、站点地图
  src/pages-news.mjs    15 条公告
  src/pages-class.mjs   班级网页 7 页
  src/pages-archive.mjs 档案室 5 页
  src/pages-media.mjs   学生作品 3 篇、《大院》校刊 3 页
  src/pages-social.mjs  留言板 70 条、原始档、2002 旧档
  src/pages-admin.mjs   维护记录、后台 4 页、工具页、备份目录
  src/pages-tools.mjs   整理工具页
  src/pages-final.mjs   结案报告 + 三个结局
  src/data.mjs          汇总 + 纯文本文件（bak/*.txt、robots.txt）
  src/build.mjs         渲染
  src/lh.js             脚本（两套版本共用）
  src/攻略.html         攻略
  src/style.css / extra.css / ie6.css

构建：

  node src/build.mjs      生成 out/（现代版）与 out/ie6/（IE6 版）
  node check.mjs          校验断链、缺图、关键内容、藏头
  node test.mjs           校验闸门与结案报告逻辑

改内容只需改 data-*.mjs，两套版本自动同步。
